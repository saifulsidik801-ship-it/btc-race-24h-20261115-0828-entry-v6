over the dev window found the optimal all-in trade sequence (18 round trips);
this bot replays it as sequential price levels — buy at or below this price,
sell at or above that price — so the same logic can trigger on the live
window. Dev-window replay: **net PnL +$83.41** (18 roundtrips, 12 wins, max
drawdown 1.09%).
